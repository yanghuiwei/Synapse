# docs 目录

## `design.md`

设计文档 —— 定位、决策记录、数据模型、模块设计。**公开文档，开源版的架构依据。**

## `ab-calibration-p6.txt`

压测引擎的分位数精度校准记录：把内置引擎与 ApacheBench (`ab`) 在统一口径下
配对对比，验证 P95 的偏差落在可接受范围内。

这是引擎可信度的证据 —— 一个说「精确分位」的压测工具，得拿出它和业界标准
工具对得上的实测数据。想知道分位算法怎么来的、误差有多大，看这份。

## 设计取舍的来龙去脉

本目录只放**结论性文档**，不放开发过程记录。某个决定为什么是现在这样，
尤其是那些「本地验不出来、只有真实环境才暴露」的问题，答案在对应模块的
头注释里 —— `core/src/lib.rs`、`mcp/src/server.rs`、`core/src/service/ops.rs`
这几处的密度最高。
